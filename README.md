# Pablo Lopez Next.js Portfolio

Modern portfolio for Pablo Lopez, focused on cybersecurity, Blue Team, cloud security, and secure software development.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- lucide-react

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```
